# 运动记录（Sport Tracker）

一个纯静态的运动记录网页应用：打开 `index.html` 即可使用，无需构建工具、无后端、零外部依赖。

## 功能

1. **添加运动记录**
   - 运动类型：跑步、骑行、游泳、健身、瑜伽、步行、其他
   - 日期（默认今天）、时长（分钟，必填）
   - 距离（km，可选）、卡路里（kcal，可选）、备注（可选）
2. **记录列表**
   - 按日期倒序展示（同一天按添加顺序倒序）
   - 每条记录可单独删除（删除前会二次确认）
3. **统计面板**
   - 总运动次数、总时长、总距离、本周运动次数（周一起算）
   - 按运动类型分组的次数统计（纯 CSS 条形展示）
4. **数据持久化**：全部数据保存在浏览器 `localStorage` 中，刷新/关闭页面不丢失

## 使用方法

- **直接打开**：双击 `index.html`，或用任意现代浏览器（Chrome / Edge / Safari / Firefox）打开即可
- **局域网/手机访问**（可选）：在目录下运行 `python3 -m http.server 8000`，然后手机浏览器访问 `http://<电脑IP>:8000`

> 注意：数据保存在"当前浏览器"里。换浏览器或清除网站数据后，记录会丢失；如需长期保存，可定期把记录截图或导出（后续可扩展导出功能）。

## 文件结构

```
sport-tracker/
├── index.html   # 页面结构（统计面板、添加表单、记录列表）
├── styles.css   # 样式（移动端优先，零依赖）
├── app.js       # 应用逻辑（增删改查、统计、localStorage 持久化）
└── README.md    # 本说明文档
```

## 技术说明

- 纯 HTML + CSS + 原生 JavaScript，无框架、无外部库、无构建步骤
- 用户输入（备注等）在渲染时做 HTML 转义，防止破坏页面结构
- 日期按 `YYYY-MM-DD` 字符串比较排序，避免时区解析偏差
